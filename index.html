Hospital Readmissions by Ownership Type

Complete

Analysis of CMS Hospital Readmissions Reduction Program data covering 2,616 hospitals. For-profit hospitals average higher excess readmission ratios than nonprofits, and the gap holds after accounting for hospital size.

The question. CMS penalizes hospitals that readmit more patients than expected given their patient mix. Does that vary by ownership, and if so, is ownership doing the work or standing in for something else?

The confound. Smaller hospitals have higher readmission ratios, and for-profit hospitals are smaller on average (median 192 heart failure discharges versus 333). So the ownership difference could have been a size difference.

Stratification. Splitting hospitals into size quartiles and comparing ownership within each one shows for-profit ratios higher in all four bands, with the gap widening at larger sizes rather than closing. The pattern also holds across all six conditions CMS measures.

What it can't show. The confidence intervals for the two ownership groups don't overlap, so the difference isn't due to random variation. That rules out chance, not confounding. Unmeasured factors like local population health or access to post-discharge care could explain both.

Flight Price Predictor

Live

A daily collector pulls flight prices from the Google Flights API into SQLite and trains a classifier to predict whether a given flight's price will rise before departure. The full pipeline, from collection through training, evaluation, and dashboard deployment, runs unattended on GitHub Actions.

Evaluation. Chronological train/test split so the model is scored only on data it hasn't seen. A random split would leak future prices into training. Every accuracy figure is reported against a majority-class baseline, since accuracy without that comparison isn't interpretable.

Data integrity. Records are tagged by source, so live API prices stay separate from the simulated fallback the collector uses when the API times out. The model trains on real prices only.

Automation. GitHub Actions runs the pipeline nightly, commits the updated database, and redeploys the dashboard to GitHub Pages.
